# 게임 씬 설계 방향

상태: 승인된 시안을 실제 경기 화면으로 연결 완료. 구현·회귀 검증은 `outputs/game-scene-implementation-2026-10-05/IMPLEMENTATION.md` 참고. 전체 자연 대국과 미실행 수락 항목은 미검증을 유지한다.

정본: `outputs/game-scene-design-2026-10-05/DESIGN.md`.

- 전체 화면의 서부 술집 타원 테이블 + 4~7인 좌석 + 하단 손패/행동 HUD.
- 시계방향 공간 배치와 공격 출발/대상을 유지한다.
- 클릭한 카드의 효과 설명 및 합법 대상 강조. 카드 이미지로 상세 확인.
- 전체 공격의 독립 제출/공동 진행 상태, 잡화점 전원 공통 공개 카드창.
- 필수 액션·응답·비용·버리기·게임 결과는 테이블 중앙의 일반 영역에서 진행한다. 배경 가림/초점 가두기/닫기 단계를 사용하지 않는다. 모바일은 참가자 요약 위, 중앙 선택, 손패 아래 구조다.
- 실제 서버 이벤트에 카드 이동/총성/방어/회복/판정/탈락/승리 연출을 연결한다.
- 모션 감소, 효과음 선택, 서버 상태와 연출 분리, 오래된 이벤트 재생 방지.
- 기존 규칙/비공개 정보/합법 행동을 유지한다. 시안의 샘플 상태 변화를 엔진에 복사하지 않는다.

UI 스킬 검색은 SF/홍보 패턴을 반환해 이 서부극 게임과 일치하는 검증된 스타일을 찾지 못했다. 직접 설계와 일반 접근성/성능 지침을 사용했다.
