[보드게임] 뱅 (BANG) 카드 설명 - NO.15-1

인물 카드 설명

게임 준비 단계에서 플레이어는 인물카드를 섞어서 하나씩 나눠 가진 후 개인 보드판 가운데에 공개합니다.

 

인물 카드 오른쪽 위에 표시가 되어 있는 총알 수가 자신의 생명력이 되고, 각 캐릭터마다 고유의 특수능력이 있습니다.

보안관은 총알 토큰을 1개 추가로 받습니다.

 

각 캐릭터들의 이름은 서부개척시대의 실존일무이거나 서부극 영화의 등장인물을 따온 것이 많다고 합니다.

 

마지막 두 캐릭터의 체력은 3입니다. 잘못 표기 됐네요...

4대 강캐라고 해서 윌리 더 키드, 캘리미티 자넷, 수지 라파예트, 슬랩 더 킬러를 많이 사용합니다.

 

이런 부조리함 때문에 확장팩이 나오고 강한 캐릭터들 보다는 약했던 캐릭터들이 더 잘 뽑히고 있습니다. 

 

하지만 수지 라파예트는 확장팩에서도 강한 캐릭터....

캐릭터 별 팁

윌리 더 키드 : 뱅이 많이 들어오고, 좋은 무기나 조준경이 하나라도 있을 때 좋습니다. 사거리가 5인 윈체스터를 끼면 사정거리 5의 볼캐닉이 탄생하는 운만 좋다면 사기입니다.

 

캘리미티 자넷 : 빗나감이나 뱅 둘중 하나라도 많이 들어오면 좋습니다. 마찬가지로 볼캐닉을 들면 화력이 좋습니다.

 

키트 칼슨 : 다음 차례 상대의 정체가 뭔지 알게 될때 좋습니다. 다음 사람에게 돌아갈 카드를 조작할 수 있기 때문에 감옥또는 다이너 마이트 콤보를 사용할 수 있습니다.

 

바트 캐시디 : 맥주, 주점이 많이 있을 때 좋습니다. 빗나감을 사용할지 카드를 받을지 고민되는 캐릭터

 

시드 케첨 : 생명력이 별로 없을 때 손에 웰스 파고 은행이나, 역마차가 있거나, 패가 많을때 좋습니다. 맥주로 회복을 못시키는 상황에서도 사용 가능해서 생존력이 좋습니다.

 

럭키 듀크 : 카드 펼치기 상황이 많을때 좋습니다. 나로 인해 다른 사람의 카드 펼치기 결과도 바뀌기 때문에 요상한 캐릭입니다.

 

주르도네 : 하트모양 카드가 많이 소비되지 않았을 때 좋습니다. 술통을 장비하면 총 2번 펼칠 수 있으므로 술통을 장비해야 합니다.

 

블랙 잭 : 이름 그대로 도박입니다.

 

벌쳐 샘 : 카드 덱이 좋은 사람이 죽었을 때 좋습니다. 보안관이 부관을 죽일 때는 카드가 전부 날아가버리는 건 마찬가지입니다. 

 

제시 존스 : 상대방이 카드가 별로 없거나, 좋은 카드가 있는 걸 알았을 때 좋습니다. 다른 플레이어가 굉장히 빡치는 캐릭터 

 

수지 라파예트 : 들어오는 카드를 즉시 쓸 수 있는 상황일 때 좋습니다. 볼캐닉을 장착한 후 뱅이 계속들어와도 좋고 맥주가 들어와도 좋고, 계속해서 카드를 사용하는 명불허전 사기 캐릭터 ... 빼고 하세요

 

페드로 라미레즈 : 버려진 카드가 좋은 카드일 때 좋습니다. 다른 플레이어가 의식하면 힘들어지지만 감옥같은 걸로 다시 열받게 할 수 있습니다.

 

슬랩 더 킬러 : 뱅을 많이 가지고 있을 때 좋습니다. 뱅을 맞는 상대가 술통으로 회피해도 빗나감 한장을 내야합니다. 하지만 마지막 죽기전 맥주는 한 장이면 됩니다.

 

로즈 둘란 : 사람들이 점점 줄어들 때, 조준경이 하나 더 있을 때 좋습니다. 볼캐닉을 장착하면 키드와 비슷하게 됩니다./

 

폴 리그레트 : 야생마를 끼거나 보안관이 되면 좋습니다. 약한 캐릭터지만 거리가 멀어지기 때문에 초반에 좋습니다. 

 

엘 그링고 : 자신한테 견제가 약하게 들어오는 경우 좋습니다. 혼자서는 뭔가 이득을 낼 수 없는 캐릭터지만 그만큼 다른 플레이어가 공격을 하기 까지 고민이 되게 하는 캐릭터입니다.
