# 장착 카드 확인창 닫기 단순화

## 변경

- 장착 카드창의 `게임판 보기`는 창을 최소화하며, 좌석 아래에 재열기 dock을 남기는 기존 ChoiceStage 동작이었다. 좁은 좌석 폭과 좌표계에서 dock 글자가 세로로 찢어지고 손패를 가렸다.
- 선택적인 확인창에 onDismiss 콜백을 추가했다. 장착 카드창과 설정창은 헤더의 `닫기` 하나로 완전히 제거되며 재열기 dock을 렌더링하지 않는다. 별도 하단 닫기 버튼도 제거했다.
- Escape도 같은 닫기 경로를 사용한다. 닫은 뒤 원래 장착/설정 버튼으로 포커스가 복원된다.
- 장착 카드 확인창은 CardInspectionHost에 portal로 표시하여 좌석의 크기·배치와 분리했다. 장착 카드 상세보기는 기존 카드 설명창을 그대로 사용한다.
- 게임의 필수 대응은 기존 중앙 table 방식이다. 레거시 modal 대응의 재열기 동작은 onDismiss 없는 호출에 유지된다. 서버 계약·게임 명령·규칙은 변경하지 않았다.

## 검증

- 전체 웹 테스트 216 PASS. 관련 stage/scene 테스트 22 PASS는 전체 결과의 부분집합이다. 단일 닫기와 dock 부재 회귀 테스트를 추가했다.
- Web TypeScript 종료 코드 0, 프로덕션 Worker/클라이언트 빌드 종료 코드 0, git diff --check 종료 코드 0.
- 실제 React 컴포넌트/고정 스냅샷으로 1280×720 데스크톱에서 내 장착 카드창의 닫기 버튼 1개, dock 0개, inspection host 사용을 확인했다.
- 장착 목록 → 카드 상세 → 상세 닫기 → 목록 닫기 경로에서 각 단계의 포커스 복원 및 최종 dialog 0/dock 0을 확인했다.
- 상대 장착 카드창의 Esc 닫기와 설정창의 단일 닫기, 420×704 모바일의 장착 창/Esc/포커스 복원을 확인했다. 모바일 창의 clientWidth=scrollWidth=393으로 가로 넘침 없음.
- QA transport는 실제 경기 명령을 실행하지 않는다. 처음 중첩된 두 창에서 닫기 버튼을 전역 선택한 브라우저 검증은 두 요소가 검색되어 중단됐다. 이후 해당 dialog로 범위를 지정하여 각 닫기 경로를 완료했다.
- 최초 97개 수락 케이스의 미검증 D06/D18, 운영 재접속 S09 및 전체 자연 게임을 새로 통과 처리하지 않는다.

정확한 배포 버전·결과는 DEPLOYMENT.md와 deployment-result.json에 기록한다.
