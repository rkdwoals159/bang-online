# 테이블 경험 개선

2026-10-05. 앞선 사용자 요청의 실제 게임 수정 기록. 새 전체 게임 씬 설계는 `outputs/game-scene-design-2026-10-05`에 별도로 저장했다.

## 실제 수정

- Gatling/Indians: 각 대상이 기다리지 않고 대응 선택을 제출. 비용/판정/피해/구제/탈락 등 후속 효과는 시계방향으로 처리하고 전체 카드 해결 뒤 승리 판정.
- 서버는 같은 공격의 유효한 응답만 최신 버전에서 재검증. 다른 행동의 버전 충돌, 명령 ID 재사용/중복 영수증 정책 유지.
- 미래 대상의 선택/카드 ID를 공개 투영에서 숨기고 제출 상태만 공유.
- 한 대상의 죽음 구제 중에도 다른 대상의 선택을 예약. 수지의 추가 뽑기와 술통 판정은 실제 처리 단계에서 실행.
- 전원 공유 대응 모달: 대기/제출/대응/완료/탈락 상태 + 현재 공개 생명력. 개인 선택은 본인에게만 노출.
- 4~7인 원형 배치와 공개 거리 표시. 좁은 화면에서는 테이블 내부 이동. 7인/긴 이름/많은 장비의 겹침을 수정하고 장비 목록 내부 스크롤.
- 공개 손패 수만큼 카드 뒷면 아이콘(기본판 전체 덱 80장 상한)과 정확한 접근 가능한 이름.
- 공개 기록 최신순: `HH:mm:ss(N초 전) - 기록`. 기록이 열리고 화면이 보일 때만 경과 시간 갱신.
- 규칙 정본 R29/D01에 사용자 요청에 따른 독립 제출 정책을 기록.

두 저장 방식에서 같은 버전의 세 대상 동시 응답이 모두 반영되는 회귀 테스트를 추가했다. 재전송 시 버전/카드 비용 중복 반영 없음. Engine은 Gatling/Indians의 선제 제출, 숨겨진 카드 ID, 술통 후속 선택, 수지 뽑기, 죽음 구제 중 예약을 점검했다.

실제 React 컴포넌트 로컬 검토: 1280×720/375×812의 4/5/6/7인 + 긴 이름/장비 6개에서 겹침 없음. 손패 80개 아이콘 표시 및 경계 넘침 없음. 공동 대응/제출 후 상태/접기 및 기록 시간 형식 확인. 전체 자연 경기 완료 검증으로 간주하지 않는다.
