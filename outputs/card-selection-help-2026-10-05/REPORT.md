# 선택 카드 효과 설명 표시

## 변경

- 선택 카드 영역에 기존 상세보기의 `getPlayingCardDescription` 데이터를 그대로 표시한다. 제목 아래에서 효과를 읽고 사용 여부를 결정할 수 있다.
- 대상·변환 방식이 없는 자기 사용 후보에서는 “이 카드 사용” 문구를 제거한다. 상대 이름, 손패/장착 카드 선택, 캐릭터 변환 방식은 별도 표시한다.
- 상세보기의 사용 대상 목록에서도 빈 안내를 제거한다.
- 16px 본문, 1.65 줄 간격, 한국어 단어 단위 줄바꿈을 적용한다. 새 API 요청이나 설명 데이터 사본은 추가하지 않는다.

## 검증

- 웹 테스트 176/176 PASS: 기존 175개와 자기 사용 안내 제거/변환 맥락 유지 회귀 1개. 웹 TypeScript 검사 PASS.
- 실제 ActionsPanel을 Vite로 실행한 로컬 브라우저 fixture에서 술통·뱅·패닉·맥주·잡화점·빗나감 변환을 선택하고 표시 내용을 확인했다.
- 술통은 효과만 표시한다. 뱅은 설명과 대상 선택지를 표시하고 선택 전 사용 버튼이 비활성이다. 패닉은 대상/손패 맥락을 유지한다. 맥주는 만피 확인 전 사용 버튼이 비활성이다. 변환은 “뱅!으로 사용”을 유지한다.
- 955px 화면과 실제 375px iframe에서 확인했다. 모바일의 긴 패닉 설명은 선택 영역 너비 309px 내에서 넘침 없이 표시된다. 취소 시 선택 영역이 사라진다.
- 화면: selected-barrel-955.png, selected-panic-375.png. 관찰 결과: browser-results.json.
- 로컬 fixture는 UI 표시와 선택 상태를 위한 것이며 카드 사용 API나 자연 게임 완료를 검증하지 않았다. 규칙과 서버 후보는 수정하지 않았다. 원본 수락 상태 95/97 및 D06/D18/S09 NOT RUN을 유지한다.
- 프로덕션 빌드와 배포 결과는 별도 로그 및 DEPLOYMENT.md에 기록한다.

기존 UI/UX 디자인 기준과 토큰을 유지했다. 스킬 검색에서 이번 요구에 직접 대응하는 결과를 확인하지 못해, 사용자 요청과 기존 디자인의 읽기·반응형 기준을 적용했다.
