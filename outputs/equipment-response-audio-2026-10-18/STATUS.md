# 장착 카드·효과음·자동 대응·탈락 처리 — 2026-10-18

## 반영 내용

1. 사용자 승인 A안: 상대 공개 장착 카드를 좌석 아래에 미니 이미지와 이름으로 상시 표시한다. 자기 장착은 손패 옆 HUD에 표시하고 중복된 자기 테이블 좌석은 숨긴다. 무기 사거리 배지와 감옥/다이너마이트 테두리를 구분하며, 그림을 누르면 기존 상세 보기를 연다.
2. 추가 피드백: 이름은 한 줄로 유지하고 카드 칸 너비를 내용에 맞춘다. 긴 다이너마이트 칸만 넓어지며, 카드 묶음은 공간에 맞춰 다음 행으로 배치한다. 카드 사용 설명/버튼은 자기 장착 영역과 분리했다. 모바일 대응 중에도 원형 좌석을 유지한다.
3. 권총·기관총은 CC0 실총 녹음으로 교체했다. 두 압축 파일은 합계 37,494바이트이며, 효과음 활성화 후 비동기 로드한다. 기존 음량·음소거·탭 숨김 정지를 지키며 다운로드/디코딩 실패 시 합성음으로 돌아간다. 설정에 두 소리 미리 듣기를 추가했다. 출처와 가공 내역은 `apps/web/public/assets/audio/CREDITS.md`에 기록했다.
4. 설정에 인디언 뱅, 뱅/개틀링 빗나감, 실제 술통 우선 자동 판정 스위치를 추가했다. 모두 기본 OFF이며 이 브라우저에 저장한다. 페이지가 열려 있을 때 서버의 합법 응답을 그대로 제출한다. 술통 실패 후 켜 둔 카드 대응을 이어 간다. 피해 수락·결투·구제·Lucky/가상 술통 선택은 자동화하지 않는다.
5. 엔진의 구제 선택이 탈락 수락 하나뿐일 때 서버가 즉시 처리하고 D14의 카드 정리·후속 효과를 이어 간다. 가능한 맥주/Sid 구제는 사용자에게 남긴다. 탈락 확인 버튼을 제거했고, 회복 가능 상태의 포기 선택은 ‘회복하지 않고 관전하기’로 표시한다. 일반 탈락과 자동 탈락 모두 DB 참가자 생존 상태도 같은 트랜잭션에서 갱신한다.
