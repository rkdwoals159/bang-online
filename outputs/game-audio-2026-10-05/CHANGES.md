# 게임 효과음 확장 — 2026-10-05

## 구현

- Web Audio로 만드는 원본 효과음 26종. 다운로드, 외부 사운드 파일, 새 라이브러리, 추가 API 요청 없음.
- 카드 받기: 종이 넘기는 소리와 작은 마찰음. 여러 장은 최대 4회 짧게 연속 재생.
- 카드 내기: 종이 이동 뒤 테이블에 내려놓는 소리. 버리기, 카드 가져오기, 잡화점 펼치기, 장착은 서로 다른 효과음.
- 무기: 장전/쇠 걸쇠 소리. 감옥: 철창 소리와 탈출/턴 건너뛰기 결과음. 다이너마이트: 장착 심지, 전달, 폭발을 구분.
- 공격, 개틀링 연사, 금속 방어음, 피해, 회복, 맥주, 결투, 인디언, 판정, 능력, 턴 전환, 탈락, 승리 구분.
- 효과음은 서버가 반영한 공개 이벤트 및 인증된 스냅샷 변화에서만 만든다. 내 카드의 새 유입도 확인하므로 역마차를 내고 2장을 받으면 순증가 1장 대신 실제 2장을 재생한다. 상대 카드의 정체는 읽거나 노출하지 않는다.
- 애니메이션 큐와 별도로 새 동기화 직후 소리를 예약한다. 동일 종류는 합치고 동기화당 최대 6종, 최대 시작 지연 375ms, 최대 활성 소스 48개로 제한한다. 카드 내기 소리가 받기 소리보다 먼저 나도록 정렬한다.
- 최초 접속, 이벤트 중복, 숨긴 탭의 기록은 기존 무음 정책 유지. 음소거와 탭 숨김은 예약된 소리도 중단한다.
- 설정에 0–100% 음량 조절 추가. 브라우저별 효과음 켜기와 음량을 저장한다. 기본 효과음은 꺼짐이며 사용자가 켜고 조작하면 재생한다.

## 검증

- 전체 웹 테스트: 207 PASS. 최종 소리 순서 수정 후 효과음/이벤트 관련 테스트 29 PASS 재실행.
- TypeScript 검사 PASS. 프로덕션 빌드 PASS. 실행 로그를 함께 저장했다.
- 실제 GameAudio의 26종 음색별 노드·주파수·예약 패턴이 서로 다름을 확인. 사용자 조작 전 무음, 음소거, 백그라운드, 음량 제한, 카드 수 및 소스 예산 검사.
- 실제 로컬 D1 경기의 역마차 사용에서 draw count=2와 play가 AudioContext에서 재생 가능 상태로 예약됨을 확인. 설정 켜기 및 키보드로 음량 50% 변경 확인. 물리적 스피커 출력이나 사람의 청취 평가를 완료했다고 주장하지 않는다.
- 최초 600ms 폴링 검증 fixture가 API 제한 응답을 스냅샷으로 취급하여 중단되어, 해당 검증 fixture의 폴링을 완화하고 미완성 응답에서는 기존 화면을 유지하도록 수정했다. 이 fixture는 배포에 포함하지 않는다.
- 원래 97개 수락 케이스 전체, D06/D18, 운영 재접속 S09, 전체 자연 게임은 이번 효과음 수정으로 새롭게 통과 처리하지 않는다.
