# 빈 손패 UI 수정

- 빈 손패 전용 클래스를 추가하고 안내를 `손패가 없어요`로 줄였다.
- 게임 화면에서는 전체 폭의 밝은 배경을 제거하고 내용 폭만큼의 작은 점선 안내를 가운데 표시한다. 데스크톱/모바일에서 약 117×42px이다.
- 일반 오류·연결 복구 안내의 스타일과 게임 명령은 변경하지 않았다. 손패가 없는 자기 차례에도 합법적인 차례 종료 버튼은 유지한다.

## 검증

- GameScene 테스트 14 PASS. 빈 손패 안내와 차례 종료 유지에 대한 회귀 테스트 포함.
- Web TypeScript 검사 종료 코드 0. 프로덕션 Worker/클라이언트 빌드 종료 코드 0.
- 실제 컴포넌트를 이용한 1280×720 빈 손패/상대 대응 화면, 420×704 빈 손패/내 차례 화면을 브라우저에서 확인했다. QA 스냅샷은 고정 데이터이며 실제 경기 명령은 실행하지 않는다.
- 스크린샷: empty-hand-desktop.png, empty-hand-mobile.png.
- 최초 97개 수락 케이스 전체, D06/D18, 운영 재접속 S09 및 전체 자연 게임을 새로 통과 처리하지 않는다.

배포 결과는 DEPLOYMENT.md와 deployment-result.json에 기록한다.
