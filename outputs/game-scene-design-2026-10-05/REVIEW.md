# 설계 시안 검토

2026-10-05. 대상은 `index.html` 기반 로컬 시안이며, 운영 경기의 전체 개편 완료를 뜻하지 않는다.

## 확인

- 1280×720, 1024×768, 375×812에서 각각 4/5/6/7인 전환: 12개 조합의 좌석 겹침 0, 화면 가로 넘침 0, 좌석 좌우 잘림 0, 깨진 카드 이미지 0.
- 7인 공동 개틀링/인디언 창: 전체 대상 상태 표시, 내가 기다리지 않고 선택, 자동 상대 응답 완료, 창 종료.
- 잡화점: 카드 그림과 이름, 내 카드 획득 상태, 뒤따르는 시계방향 샘플 선택. 실제 서버와 연결된 선택 검증은 아님.
- 카드 선택/설명/확대, 대상 선택/공격, 뽑기/회복/차례/역할/승리 시안을 브라우저에서 점검.
- 검토 중 카드 이동의 테이블 앵커 누락을 발견해 수정. 최종 재검토 결과를 별도 저장.
- 모바일 카드 설명은 두 줄 요약 + 카드 확대창. 작은 인물 그림도 44px 터치 버튼 안에 배치.

## 산출

- `scene-layout-review.json`: 인원/화면별 DOM 경계 검사.
- `table-7p.png`, `table-4p.png`, `table-mobile.png`: 테이블 시안.
- `shared-response.png`, `general-store.png`: 공동 상황창.
- `DESIGN.md`: 전체 게임 흐름/좌석/연출/구현 G01–G09/정식 검증 목록.

## 아직 검증하지 않은 사항

실제 다중 브라우저 경기 연결, 모든 인물/카드 조작, 운영 모바일 성능, 실제 FPS/저사양 성능, 실제 효과음의 청취 품질, 전체 화면 API의 모든 환경 지원, 정식 접근성 검증. 이것들은 정식 구현 G01–G09의 완료 기준이다. 시안의 자동 상대 행동/샘플 생명력 변화는 규칙 판정 코드로 사용하지 않는다.
