# 실제 게임 씬 개편 결과

2026-10-05. 승인된 시안을 실제 MatchPage에 연결했다. 단독 작업이며 공용 계약·게임 엔진·서버 판정 코드는 변경하지 않았다.

## 화면과 조작

- 4~7인 고정 시계 방향 타원 테이블, 내 좌석은 아래쪽. 서버가 제공하는 실제 거리, 생명력, 공개 장비와 손패 수를 표시한다.
- 상대 손패는 공개 수만큼 뒷면 아이콘으로 표시한다. 자기 역할과 손패만 인증된 private projection에서 읽는다.
- 하단 손패를 부채꼴로 구성했다. 사용 가능한 카드의 이미지를 누르면 즉시 선택하고 효과 설명을 보여준다. 선택된 이미지를 다시 누르면 전체 설명을 연다. 사용 불가 카드와 상대 인물/공개 장비는 이미지로 상세 확인한다.
- 공격 대상은 테이블에서 조준하거나 대상 목록에서 선택한다. 장비 교체, Janet 변환, Sid 비용, 인물 능력 등 기존 ActionsPanel의 합법 행동과 비용 선택 경로를 재사용한다.
- 초과 손패는 중앙 창에서 이미지로 순서대로 선택한다. 서버가 요구한 정확한 수와 순서를 제출한다.
- 개틀링·인디언 공동 창은 각자의 독립 제출 상태를 공유한다. 잡화점은 같은 공개 카드와 현재 선택자를 보여주고, 자기 선택 차례에 이미지로 가져간다.
- 모든 기존 pendingInteraction은 실제 ReactionPrompt를 중앙 창으로 조립한다. 일반 방어/결투/판정/죽음 구제/Lucky/Kit의 기존 선택·재시도 처리를 보존한다.
- 역할/인물 공개 화면도 같은 디자인으로 정리했고 설명은 이미지 옆의 넓은 열에 배치했다.
- 기록은 별도 서랍에서 최신순 시간 및 경과 초를 표시한다. 경과 시간 갱신은 열린 기록 컴포넌트 안에서만 일어난다.
- 메뉴는 기록·설정·전체 화면으로 줄였다. 불필요한 규칙 안내/성공 동기화 알림/덱 개수 패널은 표시하지 않는다.

## 연출과 성능 구조

- 기존 서버 이벤트 큐를 사용해 총격/개틀링 연사/방어/피해/회복/뽑기/장착/카드 사용·버림·획득·이동/다이너마이트/탈락/승리를 연결했다.
- 카드 비행은 덱·내 손패·공개 장비·상대 좌석·버림 위치의 앵커를 사용한다. 비공개 카드 비행에는 뒷면만 사용한다.
- 피해/탈락을 보여주는 동안 좌석을 유지하고 큐와 응답이 끝나면 살아 있는 좌석으로 재배치한다. 상태·거리·합법 대상은 최신 snapshot을 즉시 사용한다.
- 애니메이션은 CSS/WAAPI, 효과음은 WebAudio 합성이다. 새 그래픽·사운드 라이브러리 의존성은 추가하지 않았다. 기존 Animista 라이선스 고지를 유지한다.
- 최초 진입 및 오래된 이벤트는 재생하지 않는다. 인접 버전의 같은 차례에서 확인 가능한 카드 사용만 추가 비행으로 처리한다.
- 연출 큐는 12개, 활성 사운드 노드는 24개로 제한한다. 숨긴 탭·음소거·unmount 시 예약된 소리 노드를 중단하고 정리한다.
- 효과음 기본 꺼짐, 직접 활성화 시 재생. OS 동작 줄이기 및 앱 연출 끄기를 적용한다. 애니메이션 완료를 기다리느라 게임 입력 전체를 잠그지 않는다.

## 실제 로컬 브라우저 검증

실제 React 화면 + routeApiRequest + D1Repository + 게임 엔진을 별도의 임시 로컬 DB에 연결했다. 테스트 인원과 손패/인물을 제어해서 필요한 경로를 재현했다. QA에서는 HP를 4로 고정했다. 자연 무작위 배분 전체 대국이나 운영 DB 검증으로 해석하지 않는다. QA의 viewer 전환과 600ms polling은 운영 제품에 포함하지 않는다.

- 실제 4인 경기: 회복 맥주 → 개틀링 → 마지막 대상 먼저 빗나감 제출 → 첫 대상 방어 → 중간 대상 피해 → 공동 창 종료.
- 술통 장착 → 4인 잡화점 공개 → 각 참가자 이미지 선택 → 공개 pool 감소와 다음 선택자 이동 → 창 종료.
- 만피 맥주 확인 전 사용 불가 → 확인 후 사용 → HP 그대로 유지.
- 테이블에서 대상 선택 → 뱅! 사용 → 대상 피해 → 초과 패 2장 순서 선택·제출 → 다음 차례/자동 뽑기.
- 맥주 제출 전후 document instance 동일: 전체 페이지 리로드 없음. no-reload-review.json 참조.
- 4/5/6/7인 실제 snapshot을 각 1280×720, 1440×900, 1024×768, 375×812, 812×375에서 측정: 20개 조합의 좌석 겹침 없음, 씬 크기 일치. scene-layout-review.json 참조.
- 설정의 기본 효과음 꺼짐, 연출 끄기 class 적용, 인물 이미지 상세 설명, 실제 기록 최신순 시간 확인.

browser-command-report.json은 실제 로컬 명령 결과만 담으며 인증 쿠키·토큰·손패 내용은 포함하지 않는다. shared-response.jpg, general-store.jpg, table-7p.jpg, table-mobile.jpg는 실제 새 컴포넌트의 로컬 검증 화면이다.
