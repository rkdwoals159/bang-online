# UI/UX 및 API 개선 결과 — 2026-10-04

## 반영한 수정

- 현재 차례와 응답자를 구분한 상단 안내, 응답 → 손패/행동 → 게임판 → 접힌 공개 기록 순서.
- 손패를 한 곳에서 표시하고, 응답 대기 중에도 카드 확인·확대 가능. 사용 불가 사유는 공개 상태와 서버 선택지에만 근거한다.
- 승패·승리자·공개 역할·대기실 복귀를 먼저 보여주는 결과 화면과 비방장 대기 안내.
- 공개 로그는 허용된 이벤트 종류·플레이어 이름·공개 결과만 표시하고, 원본 payload를 출력하지 않는다.
- 대기실의 연결됨/연결 끊김/확인 중 표시. 접속 표시는 게임 버전·좌석·턴을 바꾸지 않는다.
- 역할·인물의 한국어 안내와 시작/복구 문구 정리. 01_RULES의 규칙 및 명시적 결정을 적용했다.
- 모바일 입력 영역의 가로 넘침 수정. Sites가 복사된 옛 스타일 대신 브라우저와 동일한 앱 CSS를 직접 참조하도록 변경했다.
- 동시 수동 조회는 한 요청을 공유하고, 더 최신 ACK/SSE 힌트만 후속 조회를 예약한다.
- 버전이 있는 방 명령 응답을 즉시 반영해 준비/복귀 뒤 추가 조회를 줄였다. 기존 Node 응답에는 조회 fallback을 유지한다.
- 캐시가 있는 클라이언트만 unchanged 응답을 요청한다. 인증·멤버십·저장 상태 검증 후에만 응답하며, 상관관계 불일치는 전체 조회 1회로 제한한다.
- 방·경기 읽기는 D1 batch로 일관되게 수행하고, 참가 중인 방 N+1 조회와 projection의 반복 조회를 제거했다.
- SSE는 숨겨진 상태 없는 최소 알림을 읽는다. 진행 경기 1초, 대기실 2초, 유휴 5초 주기; 접속 lease 갱신 20초/만료 45초.
- aggregate/cursor 인덱스를 추가했고 최초 migration은 수정하지 않았다. 새 게스트의 불필요한 좌석 복구 조회 및 최초 SSE 의존성을 제거했다.
- 실시간 알림이 끊겨도 HTTP 명령은 최신 상태 확인 후 사용할 수 있다. 세션 만료·권한 검사·CAS·같은 명령 재시도는 유지한다.
