# 상세 설명 잘림 수정 — 2026-10-05

## 원인과 수정

- 좌석의 `.scene-seat article`과 하단 HUD의 문단·이미지 축소 규칙이 그 안에 열린 캐릭터 상세창까지 적용됐다.
- 게임 장면에 독립적인 `scene-inspections` 호스트를 추가했다. 캐릭터와 일반 카드 상세창은 이 영역에 포털로 표시하여 좌석, 손패, 대응 영역의 축소 스타일을 받지 않는다. 게임 장면 테마와 전체 화면 표시를 유지한다.
- 캐릭터 설명은 데스크톱에서 이미지와 넓은 설명 열로, 모바일에서 이미지 아래 전체 폭의 문장으로 표시한다. 설명 색상 대비와 줄 간격을 조정했다.
- 상세창은 열 때만 생성한다. 기존 닫기, Escape, 클릭한 버튼으로 포커스 복귀를 유지한다. 필수 행동 입력은 기존 테이블 가운데 영역에 그대로 표시한다.

## 브라우저 확인

실제 GameScene 컴포넌트를 사용하는 로컬 7인 레이아웃 fixture에서 확인했다. fixture가 사용하는 캐릭터와 카드 구성은 검증 전용이며 실제 플레이를 완료한 기록은 아니다.

- 벌처 샘: 데스크톱 좌석 버튼, 모바일 내 캐릭터 버튼에서 설명 전체 표시.
- 엘 그링고: 데스크톱 상대 좌석에서 긴 설명 전체 표시.
- 1440×900: 벌처 샘 설명 열 620px, 문단 높이와 스크롤 높이가 동일하여 잘림 없음.
- 390×844: 내 캐릭터 설명 폭 337px, 높이/스크롤 높이 109px. 상세창 가로 넘침 없음.
- 844×390: 상세창 세로 스크롤 가능, 가로 넘침 없음.
- 일반 뱅! 카드: 테이블 카드 상세창을 키보드로 열어 이미지 240px와 설명 확인. 상세창의 DOM 부모는 `scene-inspections`이며 축소 영역을 조상으로 갖지 않음.
- 캐릭터 상세창 닫기 후 최초 클릭한 좌석/HUD 버튼으로 포커스 복귀 확인.
