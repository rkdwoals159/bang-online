# 지연 안내와 통신 복구 개선

2026-10-06 KST · 단독 작업

## 적용 내용

1. 행동·응답 화면에 각각 표시되던 연결 지연 문구를 제거했다. 방 화면의 안내 한 곳으로 모으고, 문제가 10초 이상 이어질 때만 표시한다. 처리 중인 버튼의 상태와 실제 규칙 위반·세션 만료 안내는 유지한다.
2. 선택적 SSE 연결이 잠깐 끊겨도 HTTP 조회와 명령 처리가 가능한 Sites에서는 연결 단절 안내를 띄우지 않는다.
3. 명령의 일시적인 통신 실패와 HTTP 5xx를 최대 세 번까지 조용히 재시도한다. 간격은 0.5초, 1초다. 새 명령을 만들지 않고 동일한 ID와 고정된 요청을 재사용하여 중복 실행을 방지한다. 숨김·종료·게스트 변경·세션 만료 시 추가 재시도를 중단한다. 잘못된 응답과 게임 규칙 거절은 자동 재전송하지 않는다.
4. 백그라운드에서 명령의 ACK와 최신 상태가 도착하면 행동·응답 화면의 잠금을 해제한다. 다른 사람의 행동으로 게임 버전만 바뀐 경우에는 제출 성공으로 판단하지 않는다. 회복한 안내가 남거나 같은 전체 공격의 응답 화면이 잠긴 채 남는 문제를 수정했다.
5. 서버 500 응답을 인터넷 연결 장애와 구분했다. 장애가 오래 지속되면 서버 응답을 다시 확인하고 있다는 안내가 표시된다.
6. 상태 조회와 이벤트 조회 사이에 명령이 커밋되면 더 최신 이벤트가 오래된 상태 응답에 섞일 수 있는 경쟁 조건을 수정했다. 이벤트를 읽은 상태의 eventSeq 이하로 제한한다. 다음 조회에서는 새 이벤트와 상태를 모두 받을 수 있다. Sites와 Node 서버에 같은 처리를 적용했다.
7. 향후 조회 500 오류의 처리 단계와 오류 종류만 서버 로그에 남긴다. 카드·세션·쿠키·요청 본문·원문 오류 메시지는 기록하지 않는다.

## 원인 확인 범위

긴 SSE 요청의 수명이나 정상 취소를 API 처리 지연으로 집계하지 않았다.
