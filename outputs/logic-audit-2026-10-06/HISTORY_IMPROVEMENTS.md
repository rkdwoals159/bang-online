# 게임 기록 개선 — 2026-10-06

## 사용자 요청과 변경

- 상대 시간은 60초 미만 `n초 전`, 60초 이상 `floor(n/60)분 전`으로 표시한다. 절대 시각 `hh:mm:ss`와 최신순 정렬은 유지한다.
- 패널을 열 때 시각과 최신 이벤트 번호를 고정한다. 열린 동안 새 이벤트가 들어와도 읽던 목록에 끼어들지 않는다. `새 기록 N개`를 누르거나 닫았다 다시 열면 목록과 시간을 갱신한다. 이전 기록 조회는 고정한 시간을 유지한다.
- 전체 기록 보관과 애니메이션용 최근 100개 이벤트 피드를 분리했다. 일반 동기화/전체 스냅샷으로 이미 보관한 기록을 삭제하지 않는다. 신원 변경과 접근 취소 때 캐시를 지운다.
- 화면은 처음 100개를 표시하고 `이전 기록 더 보기`로 100개씩 확장한다. 서버 기록은 별도 인증 API/Socket 메시지로 조회한다. 과거 조회는 게임 상태·버전·실시간 커서를 변경하지 않는다. 기존 이벤트 시퀀스 인덱스를 사용하고 최신 101개 원본 이벤트로 다음 페이지 유무를 판단한다.
- 원본 페이지에 비공개 이벤트만 있더라도 커서를 전진시켜 더 오래된 공개 기록을 조회할 수 있다. 재접속 중 누락된 중간 구간을 다시 조회하고, 늦게 도착한 과거 응답은 더 최신 복구 커서를 덮어쓰지 않는다.
- 기록창의 중첩 스크롤을 제거했다. 과거 조회 오류는 기록창에만 표시하며 게임 입력을 연결 오류 상태로 바꾸지 않는다.

원본 이벤트를 게임 상태의 불변 카드 정의와 대조해 공개 문장을 만든다. 서버가 실제로 저장하지 않은 사건은 새로 만들어 기록하지 않는다. 게임 규칙과 상태 전이 자체는 수정하지 않았다.
