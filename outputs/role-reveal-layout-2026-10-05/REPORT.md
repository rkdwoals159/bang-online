# 역할·인물 소개 줄바꿈 수정

## 원인

인물 이미지가 상세보기 버튼 래퍼로 감싸졌지만 소개 화면의 CSS는 이미지 자체만 그리드에 배치했다. 래퍼와 이름은 첫 행에 자동 배치되고 설명은 이미지 너비인 첫 열로 밀려 들어갔다. 광범위한 자손 선택자도 상세보기 내부 카드에 영향을 줄 수 있었다.

## 수정

- 소개 화면에서 이미지 또는 상세보기 래퍼를 첫 열, 이름과 설명을 두 번째 열에 명시적으로 배치한다.
- 중간 너비에서는 역할과 인물을 세로로 배치해 설명 너비를 확보한다.
- 480px 이하에서는 설명이 이미지 아래의 전체 열을 사용한다.
- 한국어 단어 중간 줄바꿈을 줄이고, 설명의 의도적인 개행을 유지한다.
- 소개 카드의 직접 자식에만 스타일을 적용해 상세보기 내부 카드와 분리한다.

## 검증

- 웹 테스트: 175/175 PASS (`web-tests.tap`). 이미지 래퍼와 설명의 명시적 그리드 위치 및 모바일 전체 열 배치 회귀 검사를 추가했다.
- 실제 RoleRevealPage를 Vite SSR로 렌더링하고 실제 소스 CSS를 사용한 로컬 fixture를 브라우저에서 확인했다. iframe의 실제 너비를 UI로 바꾸어 1022 / 375 / 320 / 1280px에서 검사했다.
- 블랙 잭 설명 너비: 각각 640 / 244 / 204 / 244px. 각 카드 컨테이너의 가로 넘침은 없었다. 수치 기록은 `layout-measurements.json`, 화면은 `reveal-1022.png`, `reveal-375.png`.
- 정적 SSR fixture이므로 API 게임 진행이나 상세보기 버튼 상호작용을 이번 검증에서 실행한 것은 아니다. 원본 수락 상태 95/97 및 D06/D18/S09 NOT RUN을 유지한다.
- 서버 및 게임 규칙 변경은 없다. 프로덕션 빌드와 배포 결과는 별도 로그 및 DEPLOYMENT.md에 기록한다.
