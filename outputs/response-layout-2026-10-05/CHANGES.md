# 응답 선택 카드 이미지 배치 수정

## 변경

- 기존 응답은 버튼과 이미지가 가로로 분리되어, 중간 폭에서 이미지가 두 선택지 사이에 놓이고 다른 응답에 속한 것처럼 보였다.
- 중앙 응답의 각 선택지를 테두리가 있는 독립 패널로 묶었다. 해당 카드 이미지는 같은 패널의 응답 버튼 위에 가운데 정렬한다. 여러 장으로 대응하는 경우도 그 패널 안에서 표시한다.
- 카드 wrapper와 이미지의 크기를 일관되게 제한하고, 일반 카드 스타일과의 우선순위 충돌을 막도록 게임 응답 영역에 선택자를 한정했다.
- 모바일은 공간에 따라 1–2열로 배치한다. 대응 중 손패 표시를 작게 하고 중앙 선택 영역을 확보한다. 짧은 화면이나 여러 선택지/복수 카드가 있는 경우 중앙 영역 안에서 세로 스크롤한다.
- 카드 클릭은 기존 상세 설명, 응답 버튼은 기존 서버 승인 선택을 유지한다. TypeScript·계약·게임 규칙·응답 명령 코드 변경 없음.

## 검증

- 관련 React 응답/게임 화면 테스트 25 PASS. Web TypeScript와 최종 프로덕션 Worker/클라이언트 빌드 종료 코드 0. git diff --check 종료 코드 0.
- 실제 React 컴포넌트, app-shell 및 고정 스냅샷을 사용해 브라우저에서 950px 단일 카드/복수 카드/여러 선택지, 760px 여러 선택지, 420px 단일/복수 카드, 320px 복수 카드를 확인했다.
- 모든 확인에서 카드 이미지가 자신의 선택지 사각형 안에 있고, 해당 버튼보다 위에 있으며, 다른 응답 버튼과 겹치지 않았다. 선택지 영역 clientWidth=scrollWidth로 가로 넘침 없음. 응답 버튼 높이 최소 44px 유지. 상세보기 연결 및 응답 버튼 활성화 확인.
- 420×704 단일 카드 응답에서는 카드 이미지와 두 대응 버튼을 함께 표시하고, 중앙 body clientHeight=scrollHeight=244로 세로 넘침도 없다.
- DOM 측정은 layout-checks.json, 화면은 response-desktop.png와 response-mobile.png에 저장했다. QA transport는 실제 경기 명령을 실행하지 않는다.
- 최초 97개 수락 케이스의 미검증 D06/D18, 운영 재접속 S09 및 전체 자연 게임을 새로 통과 처리하지 않는다.

정확한 운영 배포 결과는 DEPLOYMENT.md와 deployment-result.json에 기록한다.
